Detailed Description

Destroys entities flagged for removal unless they are explicitly marked as Indestructible.

This system checks for PendingDestroy on all entities and removes them from the game world unless an Indestructible component is present. It ensures deferred cleanup and allows other systems to react before final deletion.

Useful for controlling death animations, logging, and system order guarantees.
